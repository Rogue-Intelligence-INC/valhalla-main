# 瓦序 VAL-DAL 主程序介绍

> A测版（Alpha）· Rogue Intelligence Inc.（美国特拉华州）

## 一句话介绍

瓦序 VAL-DAL 是一个**装在自己电脑上的 AI 助手**：先在你的本地资料里找依据，再让模型组织回答；能读屏幕、读文件、联网查找，也能在你确认后替你操作电脑。默认完全离线，资料和对话都留在本机。

## 适合谁

- **个人用户**：想要一个不联网也能用、不把资料交给云端的 AI 助手。
- **知识型岗位**：手里有大量文档、表格、规章，需要"问一句就能找到出处"。
- **小团队 / 企业**：在一台电脑上配置多个本地账号，按项目归档对话，不依赖外部服务。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| 对话 | 类似主流 AI 桌面应用：左侧会话列表，中间对话，右侧边栏显示执行进度、上下文与权限。回答可复制、朗读、重新生成、导出为 Markdown。 |
| 本地知识库 | 手写笔记（一行一条）加批量导入资料。支持 txt、md、csv、tsv、json、jsonl、html、xml、rtf、log、docx、xlsx、pptx、pdf。导入的资料单独存放并标记"待审核"，提问时先在其中检索依据。 |
| 长期记忆 | 任意一条回答可一键存入知识库，之后的对话会引用。 |
| 文件上下文 | 把文本、代码、表格等文件附加到本轮对话，直接针对文件提问。 |
| 屏幕识别与 OCR | 识别当前屏幕上的文字和界面控件，或对图片做文字识别，然后让助手解释或继续处理。 |
| 联网查找 | 需要最新信息时先检索网上来源，结果并入本轮上下文；可随时切回"仅本地"。 |
| 电脑控制 | **默认关闭**。开启并确认后，助手可以执行读屏、点击、输入、按键、滚动等操作。 |
| 任务模式与定时 | 任务模式下助手直接执行并汇报结果；也可以把当前输入设成定时执行。 |
| 工作区与项目 | 按工作区、项目归档对话，适合同时推进多件事。 |
| 本地账号 | 本机多账号与角色权限，可停用、重置密码；企业版可扩展账号数量。 |
| 多模型 | 内置 Qwen2.5-0.5B，可在"管线与模型"里下载和切换 Qwen、Llama、Mistral、Gemma、Phi 等开源模型。 |
| 在线大模型（可选） | 需要更强的长回答时，可用 CDK 开通官方在线模型；仍然先在本地检索，再交给在线模型写回答。 |
| 划词菜单 | 在回答、OCR 结果或资料中选中文字，可朗读、翻译、解释或带入对话继续讨论。 |
| 双语界面 | 中文 / English / 跟随系统，界面文字和助手提示同步切换。 |

## 它是怎么工作的（概述）

1. **理解问题**：结合当前对话、附加文件、屏幕内容判断你要什么。
2. **本地检索**：在你的知识库里找出与问题相关的段落，作为回答依据。
3. **组织回答**：把依据交给模型写成通顺的回答；同一会话内模型保持加载，多轮对话不用反复启动。
4. **执行（可选）**：如果你开启了任务模式或电脑控制，再按确认过的步骤执行。

"先检索、后生成"的好处是：回答的依据来自你自己的资料，可以回头核对；即使是小模型，也能用好知识库里已有的内容。

## 隐私与离线

- 模型、知识库、对话记录都在本机，断网也能正常使用。
- 联网查找、在线大模型都是**手动开启**的可选项。
- 电脑控制默认关闭，开启前需要确认。

## 运行环境与安装

- 系统：Windows 10（1809 及以上）或 Windows 11。
- 显卡：有 NVIDIA 显卡时自动用 GPU 加速（安装包自带 CUDA 12 运行库）；没有显卡也能运行，只是慢一些。
- 安装：运行 `瓦序VAL-DAL_A测版_安装程序.exe`，一路下一步即可，默认装到 `C:\Ai\VAL-DAL`，并创建桌面快捷方式。内置 0.5B 模型，装完即可离线使用。
- 数据位置：主程序的设置和资料在安装目录下的 `data\main`，与教师版、学生版互不干扰。

## 产品家族

| 产品 | 用途 |
| --- | --- |
| **主程序（本文）** | 通用本地 AI 助手：知识库、屏幕、文件、联网、电脑控制、任务。 |
| 教师版 | 按课标出卷（DOC / PDF）、读卷 OCR、批量批阅；批阅结果按学号归入**学情档案**，可查看每个学生的学习缺失、以中考 / 高考为标准的能力评估和学习曲线，并导入学生自测记录。 |
| 学生版 | 学伴对话、课程表与预习、拍课本讲解、错题本；新增**测评与学情**：扫描做完的试卷由 AI 打分，按考点找出学习缺失，以中考 / 高考为标准评估能力并画出学习曲线，可导出给老师。 |
| 安卓版 | 主应用连接本机使用；学生 / 教师应用内置离线小模型，功能与桌面学生版、教师版对应。 |

## 内部测试数据（仅供参考）

以下来自我们在 RTX 4090 + Qwen2.5-0.5B 上的内部测试，不是第三方评测，正式评测结果将另行发布：

- 知识留存（存储通道）：100%
- 与 Linux 版本的功能一致性：40 / 40 项检查通过
- 0.5B 小模型混合选择题解码：约 63%
- 连续 20 轮使用中，本地知识结构持续增长（19 → 34 个片段）

## A测版说明与已知限制

- 当前为 A测版，功能和界面仍会调整。
- 0.5B 小模型适合检索型问答和短回答；复杂推理、长文写作建议换更大的模型或开通在线版。
- CDK 目前在本地校验，公开发售前会改为服务器校验。
- 联网查找、在线模型需要网络；其余功能离线可用。
